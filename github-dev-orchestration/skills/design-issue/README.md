# Design Issue

Issue-level design belongs inside delivery, after the environment is ready.
Keep effort proportional to the task and let the manifest selected by
`RESOURCE-MAP.yml` guide choices. Required graph changes suggest planning; only real
waits require handoff. The caller supplies decision authority and required
approvals; this skill settles and records the design without selecting
approval policy. Design notes explain rationale, not another roadmap.

The human-approval question must contain a readable design brief, not just a
link. Offer design approval or revision only; approval does not start
implementation or require handoff. Return the accepted design to the caller.
