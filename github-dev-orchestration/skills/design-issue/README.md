# Design Issue

Design develops or revises an issue's solution without requiring a claim or
prepared worktree. Preflight loads missing orchestration context; input is
the target GitHub issue.

Keep the proposal focused on scope, key decisions, and tradeoffs. Confirm
approval from the user or within delegated authority before posting or updating
a `## DESIGN` issue comment with the approved design.

Record the approved outcome, not every draft. The skill and comment remain
optional for implementation or publication unless explicitly required by the
project. Approval does not itself start implementation.
