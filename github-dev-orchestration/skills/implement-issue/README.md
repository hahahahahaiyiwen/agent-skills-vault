# Implement Issue

Implement the issue's scope in its task worktree using repository guidance
and any approved design. Preflight loads missing orchestration context; input
is the target GitHub issue.

Verify changed behavior with focused tests and required project checks before
reporting completion. Record the finished implementation in a `## IMPLEMENT`
issue comment with the change summary, verification results, and remaining
limitations.

A separate design action is not a universal prerequisite. Implementation does
not automatically start self-review or PR publication.
