# Implement Issue

Implementation owns the issue-scoped change and its evidence, not planning
graph state or PR submission. Honor the manifest selected by `RESOURCE-MAP.yml`.
Preserve focused validation, repository conventions, explicit failures, durable
remote progress, and pre-PR self-review. Non-code outcomes need no empty PR.
Material approach changes return `not_ready` with a suggested design step;
routine implementation within an accepted design stays autonomous.
Return when implementation is ready; do not start the suggested review or PR work.
